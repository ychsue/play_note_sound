# 跑馬燈功能

我在想將歌詞在 `開始播放` 的按鈕上方，以跑馬燈的方式顯示出來。

1. Play: 每個字都放在一個 `<span>` 裡面(還是有更好的?)，寬度正比於該音的長度，該字就在該 `<span>` 的中間位置。邊播放就邊移動整條歌詞，盡量讓正在播放的音在正中間，當播放到該字的音時，就框起來吧？然後有連續滾動的效果(有點像 scrolling)。
2. Pause: 目前缺 pause 與 stop 的功能，暫停的話就暫停滾動，停止的話就回到最初的位置。
3. Assign: 既然像是 Scrolling，那麼，可以讓使用者可以移到任何想要的音的位置來 play 嗎？

## Gemini 的回答

不客氣！看到這個專案從簡單的 Python 腳本，一步步演變成一個具有**視覺滾動、即時編輯、以及精確音訊排程**的網頁應用程式，真的非常有成就感！

這套系統目前已經具備了現代音樂軟體（DAW）的核心邏輯。在你開始嘗試之前，這裡有幾個「專業玩家級」的小建議，可以讓你的測試更順利：

### 1. 關於「暫停與跳轉」的物理特性

在 `music_core.js` 中我們加入了 `activeNodes` 追蹤。這非常重要，因為 Web Audio API 的聲音一旦「排程」下去，瀏覽器就會在背景執行。如果沒有 `stopAllNotes()`，當你按暫停時，已經排好隊的音符還是會繼續唱完。現在的設計確保了按下 Pause 的瞬間，硬體會立刻靜音。

### 2. 歌詞軌道的視覺微調

如果你發現歌詞滾動時字體太擠，可以在 `main.js` 中調整 `PIXELS_PER_BEAT`：

* 想看細一點（像縮時攝影）：設為 `50`。
* 想看清楚歌詞：設為 `100` 或更大。

### 3. 部署 GitHub Pages 的最後檢查

上傳到 GitHub `docs` 資料夾（或根目錄）時，請確保：

* `index.html` 裡面引用的路徑是 `src="music_core.js"` 而不是絕對路徑。
* 如果你的 `sample.json` 也在同一個資料夾，`fetch("sample.json")` 就能正常運作。

你的程式碼現在已經非常強大且模組化了：

* **`music_core.js`**：你的「音效卡驅動程式」。

* **`index.html`**：你的「舞台控制台」。
